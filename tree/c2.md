# 🖥️ Command & Control Frameworks

C2 / post-exploitation frameworks, implants, and tunnel helpers — for authorized adversary simulation, C2-traffic detection testing, and lab post-exploitation.

## Open-Source C2 Frameworks

Sliver ⭐


#### Sliver ⭐

Open-source cross-platform adversary-emulation framework (BishopFox); Go implants are dynamically compiled with per-binary encryption keys and support C2 over mTLS, WireGuard, HTTP(S), and DNS.

**When:** Your default lab/red-team C2 when you want a framework blue teams can profile exhaustively without commercial licensing.

**Effort:** medium  ·  **Rating:** 5/5

**Install:** `curl https://sliver.sh/install | sudo bash`

**URL:** https://github.com/BishopFox/sliver

**Alternatives:** havoc, mythic, merlin, villain


#### Havoc

Modern malleable post-exploitation framework pairing a Qt client with a Go teamserver; the Demon agent speaks AES-encrypted HTTP(S)/SMB and uses indirect syscalls. Maintenance stopped — repo archived Feb 2026 — yet it stays a heavily studied, MITRE-tracked (S1229) traffic class.

**When:** Lab and detection research against a well-documented post-exploitation stack (tunnel, AMSI/ETW patching, BOF/COFF loading) whose artifacts most EDRs now fingerprint.

**Effort:** advanced  ·  **Rating:** 4/5

**Install:** `git clone https://github.com/HavocFramework/Havoc && cd Havoc && ./build.sh`

**URL:** https://github.com/HavocFramework/Havoc

**Alternatives:** sliver, mythic, villain


#### Mythic

Collaborative, Docker-based post-exploitation platform whose core ships no agents; you install agent payload types (Apollo/.NET, Athena/Rust, and others) and C2 profiles as separate containers via mythic-cli and the Mythic scripting API.

**When:** Long-running lab engagements needing a pluggable, community-vetted agent ecosystem, cross-team collaboration, and GraphQL/automation hooks for red-team reporting.

**Effort:** medium  ·  **Rating:** 5/5

**Install:** `curl -sSL https://raw.githubusercontent.com/its-a-feature/Mythic/master/install.sh | bash`

**URL:** https://github.com/its-a-feature/Mythic

**Alternatives:** sliver, merlin, covenant


#### Merlin

Go-based post-exploitation server/agent pair communicating over HTTP/1.1, HTTP/2, h2c, and HTTP/3 (QUIC) — a practical model for non-TLS and modern protocol beaconing.

**When:** Lab tests of HTTP/2 and QUIC transport detection, since most defensive tuning focuses on plain HTTPS beacon patterns.

**Effort:** medium  ·  **Rating:** 4/5

**Install:** `wget https://github.com/Ne0nd0g/merlin/releases/latest/download/merlinServer-Linux-x64.7z`

**URL:** https://github.com/Ne0nd0g/merlin

**Alternatives:** sliver, mythic


#### Covenant

Collaborative .NET C2 with a browser UI whose Grunt implants are dynamically compiled C# — the canonical worked example of .NET post-exploitation patterns (in-memory loading, AMSI/ETW patching, SMB P2P). Effectively unmaintained since ~2021 (last push 2024); now a lab/museum reference and signature-rich detection target.

**When:** Studying .NET post-exploitation design and beating on well-known signatures in the lab; treat it as a legacy framework, not for live operations.

**Effort:** medium  ·  **Rating:** 3/5

**Install:** `git clone https://github.com/cobbr/Covenant && cd Covenant/Covenant && dotnet build -c Release`

**URL:** https://github.com/cobbr/Covenant

**Alternatives:** mythic, sliver


#### Villain

High-level stage 0/1 C2 handler for many reverse-TCP and HoaxShell (HTTPS) shells, shipped with Windows/Linux payload templates, fileless scripting, and cross-instance session sharing.

**When:** Quick-sided Kali lab work that needs concurrent shell handling and payload-template experimentation without standing up a full framework.

**Effort:** easy  ·  **Rating:** 4/5

**Install:** `sudo apt install villain`

**URL:** https://github.com/t3l3machus/Villain

**Alternatives:** sliver, havoc






## Commercial C2 Frameworks

Cobalt Strike ⭐


#### Cobalt Strike ⭐

Commercial threat-emulation platform (Fortra) and the de-facto reference C2; Malleable C2 profiles reshape HTTP(S)/DNS beacon traffic into the traffic shapes blue teams tune their detections around. Vetted licensing only: new licenses roughly $3.5k–$10k/user/yr, with cracked builds aggressively taken down.

**When:** When you are an authorized red team that can buy it, or to study the beacon patterns that dominate C2 detection research.

**Effort:** medium  ·  **Rating:** 5/5

**Install:** `licensed download from cobaltstrike.com (vendor-vetted)`

**URL:** https://www.cobaltstrike.com

**Alternatives:** sliver, brute ratel c4, nighthawk


#### Brute Ratel C4

Commercial evasion-first C2 (Dark Vortex) built around the Badger implant and Commander UI, with EDR-bypass techniques (sleep obfuscation, hook removal) and a custom compiler introduced in v2.3 'Flux'. Single-user one-year license ~$3250; authorized owners only.

**When:** Stress-testing EDR detections against an evasion-focused implant in your licensed lab; build a Brute Ratel detection story before it is needed in an incident.

**Effort:** medium  ·  **Rating:** 4/5

**Install:** `licensed download from bruteratel.com (vendor-vetted)`

**URL:** https://bruteratel.com

**Alternatives:** nighthawk, sliver


#### Nighthawk

Commercial C2 from MDSec's ActiveBreach team engineered for high-assurance detection evasion, with per-build watermarking (builds are attributable) and online-activated, hardware-locked licensing. ~$10k/user/yr, minimum three seats, UK export-controlled and vendor-vetted.

**When:** Budgeted, mature red teams that can meet its vetting and seat minimum; otherwise, its published tradecraft makes a documented benchmark for hardening detector coverage.

**Effort:** advanced  ·  **Rating:** 4/5

**Install:** `licensed download from nighthawkc2.io (vendor-vetted)`

**URL:** https://nighthawkc2.io

**Alternatives:** cobalt strike, brute ratel c4






## Agents & Implant Builders

CrossC2 ⭐


#### CrossC2 ⭐

Extension that generates cross-platform beacons for Cobalt Strike (Linux, macOS, Android/ARM, even ESXi) from a configured HTTPS listener, via genCrossC2 plus automatic Malleable C2 profile handling.

**When:** Extending a Cobalt Strike lab to authorized non-Windows assets where stock Beacon cannot run, or studying cross-platform beacon metadata.

**Effort:** advanced  ·  **Rating:** 4/5

**Install:** `Download genCrossC2 + CrossC2.cna from the GitHub release`

**URL:** https://github.com/gloxec/CrossC2

**Alternatives:** donut


#### Donut

Generates position-independent shellcode that stages .NET assemblies, PE files, and VBS/JScript entirely in memory, so a lab agent can be delivered without touching disk on the test host.

**When:** Producing an in-memory delivery stage for a lab agent and observing how loaders that patch AMSI/ETW look from a defender's perspective.

**Effort:** easy  ·  **Rating:** 4/5

**Install:** `pip3 install donut-shellcode`

**URL:** https://github.com/TheWover/donut

**Alternatives:** crossc2






## C2 Helpers & Tunnel Boosters

Ligolo-ng ⭐


#### Ligolo-ng ⭐

Tunneling/pivoting tool that exposes a TUN interface and routes TCP/UDP through an agent over reverse TCP/TLS, reaching remote lab subnets without SOCKS/proxychains, with a web UI and autoroute since v0.8.

**When:** Reaching the rest of an authorized test network from a C2 foothold — pivot activity blue teams should recognize and alert on.

**Effort:** medium  ·  **Rating:** 5/5

**Install:** `Download proxy & agent binaries from GitHub releases`

**URL:** https://github.com/nicocha30/ligolo-ng

**Alternatives:** chisel


#### Chisel

Single-binary fast TCP/UDP tunnel carried over HTTP(S)/WebSocket (SSH-secured) with reverse port-forwarding and SOCKS — communication that reads as ordinary WebSocket/web traffic to defenders.

**When:** Bridging egress-filtered lab segments to your C2, or tunnelling any service where the traffic should blend with normal HTTPS.

**Effort:** easy  ·  **Rating:** 4/5

**Install:** `go install github.com/jpillora/chisel@latest`

**URL:** https://github.com/jpillora/chisel

**Alternatives:** ligolo-ng
