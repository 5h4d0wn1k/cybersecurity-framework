# 🖥️ Command & Control Frameworks

C2 / post-exploitation frameworks, communication profiles, payload & beacon kits, and infrastructure helpers — for authorized adversary simulation, C2-traffic detection testing, and lab post-exploitation.

#### Open-Source Frameworks


##### Sliver ⭐

Open-source cross-platform adversary-emulation framework (BishopFox); Go implants are dynamically compiled with per-binary encryption keys and support C2 over mTLS, WireGuard, HTTP(S), and DNS.

**When:** Your default lab/red-team C2 when you want a framework blue teams can profile exhaustively without commercial licensing.

**Effort:** medium  ·  **Rating:** 5/5

**Install:** `curl https://sliver.sh/install | sudo bash`

**URL:** https://github.com/BishopFox/sliver

**Alternatives:** havoc, mythic, merlin, villain


##### Mythic

Collaborative, Docker-based post-exploitation platform whose core ships no agents; you install agent payload types (Apollo/.NET, Athena/Rust, and others) and C2 profiles as separate containers via mythic-cli and the Mythic scripting API.

**When:** Long-running lab engagements needing a pluggable, community-vetted agent ecosystem, cross-team collaboration, and GraphQL/automation hooks for red-team reporting.

**Effort:** medium  ·  **Rating:** 5/5

**Install:** `curl -sSL https://raw.githubusercontent.com/its-a-feature/Mythic/master/install.sh | bash`

**URL:** https://github.com/its-a-feature/Mythic

**Alternatives:** sliver, merlin, covenant


##### Empire

BC-Security's maintained fork of PowerShell Empire: PowerShell, Python, and C# agents with HTTP, HTTPS, HTTP(S)-SMB, and WebSocket listeners plus a REST API that Starkiller builds on.

**When:** Classic PowerShell-heavy post-exploitation tradecraft whose agent traffic pairs naturally with the Starkiller UI; still the reference for Empire-style stager patterns.

**Effort:** medium  ·  **Rating:** 4/5

**Install:** `git clone --recursive https://github.com/BC-SECURITY/Empire.git`

**URL:** https://github.com/BC-SECURITY/Empire

**Alternatives:** starkiller, sliver, mythic


##### Havoc

Modern malleable post-exploitation framework pairing a Qt client with a Go teamserver; the Demon agent speaks AES-encrypted HTTP(S)/SMB and uses indirect syscalls. Maintenance stopped — repo archived Feb 2026 — yet it stays a heavily studied, MITRE-tracked (S1229) traffic class.

**When:** Lab and detection research against a well-documented post-exploitation stack (tunnel, AMSI/ETW patching, BOF/COFF loading) whose artifacts most EDRs now fingerprint.

**Effort:** advanced  ·  **Rating:** 4/5

**Install:** `git clone https://github.com/HavocFramework/Havoc && cd Havoc && ./build.sh`

**URL:** https://github.com/HavocFramework/Havoc

**Alternatives:** sliver, mythic, villain


##### Merlin

Go-based post-exploitation server/agent pair communicating over HTTP/1.1, HTTP/2, h2c, and HTTP/3 (QUIC) — a practical model for non-TLS and modern protocol beaconing.

**When:** Lab tests of HTTP/2 and QUIC transport detection, since most defensive tuning focuses on plain HTTPS beacon patterns.

**Effort:** medium  ·  **Rating:** 4/5

**Install:** `wget https://github.com/Ne0nd0g/merlin/releases/latest/download/merlinServer-Linux-x64.7z`

**URL:** https://github.com/Ne0nd0g/merlin

**Alternatives:** sliver, mythic


##### Covenant

Collaborative .NET C2 with a browser UI whose Grunt implants are dynamically compiled C# — the canonical worked example of .NET post-exploitation patterns (in-memory loading, AMSI/ETW patching, SMB P2P). Effectively unmaintained since ~2021 (last push 2024); now a lab/museum reference and signature-rich detection target.

**When:** Studying .NET post-exploitation design and beating on well-known signatures in the lab; treat it as a legacy framework, not for live operations.

**Effort:** medium  ·  **Rating:** 3/5

**Install:** `git clone https://github.com/cobbr/Covenant && cd Covenant/Covenant && dotnet build -c Release`

**URL:** https://github.com/cobbr/Covenant

**Alternatives:** mythic, sliver


##### Villain

High-level stage 0/1 C2 handler for many reverse-TCP and HoaxShell (HTTPS) shells, shipped with Windows/Linux payload templates, fileless scripting, and cross-instance session sharing.

**When:** Quick-sided Kali lab work that needs concurrent shell handling and payload-template experimentation without standing up a full framework.

**Effort:** easy  ·  **Rating:** 4/5

**Install:** `sudo apt install villain`

**URL:** https://github.com/t3l3machus/Villain

**Alternatives:** sliver, havoc


##### PoshC2

Python-based C2 with PowerShell and C# tasking, impacket-driven implant generation, and in-memory staging — a lightweight, well-documented write-up of multi-listener C2 architecture.

**When:** A small, quick-to-stand-up C2 for teaching listener/server concepts or comparing stager patterns against a mainstream framework.

**Effort:** medium  ·  **Rating:** 4/5

**Install:** `git clone --recurse-submodules https://github.com/nettitude/PoshC2.git`

**URL:** https://github.com/nettitude/PoshC2

**Alternatives:** sliver, empire


##### Metasploit Framework

Rapid7's framework in its C2 role: multi/handler listeners, staged Meterpreter/Python payloads, session and pivot management, plus the post-exploitation and exploit modules that hash-complete the ecosystem behind msfvenom.

**When:** A lab C2/orchestrator when you want built-in listeners plus post-exploitation modules in one place; the baseline everyone's detection stack is tuned to.

**Effort:** medium  ·  **Rating:** 5/5

**Install:** `curl https://raw.githubusercontent.com/rapid7/metasploit-framework/master/msfupdate | sudo bash`

**URL:** https://github.com/rapid7/metasploit-framework

**Alternatives:** msfvenom, sliver


#### Commercial & Licensed

#### Malleable C2 Profiles


##### Profile Generators


###### C2concealer ⭐

Red Siege's generator that crafts random, unique Malleable C2 profiles for Cobalt Strike and validates them by checking profile syntax against a reference server.

**When:** Generate a fresh, randomized C2 profile per lab campaign so beacon traffic doesn't match known profile hashes.

**Effort:** medium  ·  **Rating:** 4/5

**URL:** https://github.com/RedSiege/C2concealer

**Alternatives:** malleable-c2-randomizer, pymalleablec2


###### Malleable-C2-Randomizer

BluScreenofJeff's framework of profile-randomization scripts that shuffle URI paths, user-agents, and headers to defeat simple static signature matching.

**When:** Lab experiments in yanking profile parts around and measuring how detection shifts between variants.

**Effort:** medium  ·  **Rating:** 4/5

**Install:** `git clone https://github.com/bluscreenofjeff/Malleable-C2-Randomizer.git`

**URL:** https://github.com/bluscreenofjeff/Malleable-C2-Randomizer

**Alternatives:** c2concealer, pymalleablec2


###### pyMalleableC2

byt3bl33d3r's Python library that reads and rewrites Malleable C2 profile files programmatically, letting scripts tweak jitter, URIs, and headers in bulk.

## Payload & Beacon Development



#### Payload Generation


##### msfvenom ⭐

The payload generator inside Metasploit: raw, shellcode, and staged/stageless payloads for Windows, Linux, macOS, Android, and web platforms, with encoders and format outputs for every delivery stage.

**When:** Authorized tests needing a payload in exactly the format your C2 staging (or a loader like Donut/ScareCrow) expects.

**Effort:** easy  ·  **Rating:** 5/5

**Install:** `apt install metasploit-framework  # then: msfvenom --list payloads`

**URL:** https://github.com/rapid7/metasploit-framework

**Alternatives:** donut, scarecrow


##### Donut

Generates position-independent shellcode that stages .NET assemblies, PE files, and VBS/JScript entirely in memory, so a lab agent can be delivered without touching disk on the test host.

**When:** Producing an in-memory delivery stage for a lab agent and observing how loaders that patch AMSI/ETW look from a defender's perspective.

**Effort:** easy  ·  **Rating:** 4/5

**Install:** `pip3 install donut-shellcode`

**URL:** https://github.com/TheWover/donut

**Alternatives:** crossc2


##### ScareCrow

Tylous's loader builder that wraps position-independent shellcode in benign-trusted formats (MSI, XLL, DLL sideload/renamed, HTA) using signed JScript/JS patterns for lab delivery testing.

**When:** Lab research on how standard loaders hold up against modern EDR signatures — generate a loader and see what telemetry it leaves behind.

**Effort:** medium  ·  **Rating:** 4/5

**Install:** `git clone https://github.com/Tylous/ScareCrow.git`

**URL:** https://github.com/Tylous/ScareCrow

**Alternatives:** donut


#### Beacon & Stager Builders


##### CrossC2 ⭐

Extension that generates cross-platform beacons for Cobalt Strike (Linux, macOS, Android/ARM, even ESXi) from a configured HTTPS listener, via genCrossC2 plus automatic Malleable C2 profile handling.

**When:** Extending a Cobalt Strike lab to authorized non-Windows assets where stock Beacon cannot run, or studying cross-platform beacon metadata.

**Effort:** advanced  ·  **Rating:** 4/5

**Install:** `Download genCrossC2 + CrossC2.cna from the GitHub release`

**URL:** https://github.com/gloxec/CrossC2

**Alternatives:** donut


##### SILENTTRINITY

byt3bl33d3r's cross-platform post-exploitation C2 shell with a Python audit kit whose agents stage C# assemblies entirely in memory over HTTP — a reference for IronPython/C# and memory-only agent design.

**When:** Studying memory-only C# stager architecture and the older 'Tasking the CLR' implant generation model in a lab.

**Effort:** advanced  ·  **Rating:** 4/5

**Install:** `git clone https://github.com/byt3bl33d3r/SILENTTRINITY.git`

**URL:** https://github.com/byt3bl33d3r/SILENTTRINITY

## C2 Infrastructure



#### Pivoting & Tunnels


##### Ligolo-ng ⭐

Tunneling/pivoting tool that exposes a TUN interface and routes TCP/UDP through an agent over reverse TCP/TLS, reaching remote lab subnets without SOCKS/proxychains, with a web UI and autoroute since v0.8.

**When:** Reaching the rest of an authorized test network from a C2 foothold — pivot activity blue teams should recognize and alert on.

**Effort:** medium  ·  **Rating:** 5/5

**Install:** `Download proxy & agent binaries from GitHub releases`

**URL:** https://github.com/nicocha30/ligolo-ng

**Alternatives:** chisel


##### Chisel

Single-binary fast TCP/UDP tunnel carried over HTTP(S)/WebSocket (SSH-secured) with reverse port-forwarding and SOCKS — communication that reads as ordinary WebSocket/web traffic to defenders.

**When:** Bridging egress-filtered lab segments to your C2, or tunnelling any service where the traffic should blend with normal HTTPS.

**Effort:** easy  ·  **Rating:** 4/5

**Install:** `go install github.com/jpillora/chisel@latest`

**URL:** https://github.com/jpillora/chisel

**Alternatives:** ligolo-ng


#### Edge, CDN & Fronting


##### cdncheck ⭐

ProjectDiscovery's CLI (with Go library and nuclei integration) that tags an IP/host as CDN, cloud, or WAF and can surface the true origin, mapping whether your C2 listeners sit behind hosted edge layers.

**When:** Before fronting a C2 listener: know whether there's already a CDN/WAF in front of a host and whether the origin leaks elsewhere.

**Effort:** easy  ·  **Rating:** 4/5

**Install:** `go install -v github.com/projectdiscovery/cdncheck/cmd/cdncheck@latest`

**URL:** https://github.com/projectdiscovery/cdncheck

**Alternatives:** cloudflared


##### cloudflared

Cloudflare Tunnel client: exposes a local listener through Cloudflare's edge (e.g. quick tunnels) so inbound C2/redirector traffic arrives via a CDN hop rather than your bare IP.

**When:** Putting a lab C2 behind a legitimate edge service and validating that middlebox-only checks still detect your channel.

**Effort:** medium  ·  **Rating:** 4/5

**Install:** `wget https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64`

**URL:** https://github.com/cloudflare/cloudflared

**Alternatives:** cdncheck


#### Multi-hop Proxies & Chains


##### gost ⭐

GO Simple Tunnel: multi-hop proxy chains (SOCKS5/HTTP/SSH/relay) with port forwarding, load balancing, and protocol obfuscation — a scriptable chaining engine for C2 redirector piping.

**When:** Chain multiple redirectors/proxies on an authorized lab path and get per-hop logs while tuning traffic shapes.

**Effort:** medium  ·  **Rating:** 4/5

**Install:** `bash <(curl -fsSL https://raw.githubusercontent.com/go-gost/gost/main/install.sh)`

**URL:** https://github.com/go-gost/gost

**Alternatives:** stowaway, chisel


##### Stowaway

ph4ntonn's anti-detection multi-hop proxy for C2: agent mesh nodes support Socks5 and SSH forwarding with each hop adding a layer of encryption.

**When:** Multi-hop proxy meshes in lab engagements where you want per-node encryption layers instead of plain port-forwarding.

**Effort:** advanced  ·  **Rating:** 4/5

**Install:** `git clone https://github.com/ph4ntonn/Stowaway.git`

**URL:** https://github.com/ph4ntonn/Stowaway

**Alternatives:** gost



## Documentation & Learning



#### Docs & References


##### C2 Matrix ⭐

The community-maintained comparison of C2 frameworks: features, capabilities, listeners, transports, BOF support, and reporting across close to 100 frameworks, with a lab harness and Slingshot VM for testing them.

**When:** Pick a C2 or compare implementation kits: one table to evaluate listeners, transports, and reporting before you install anything.

**Effort:** easy  ·  **Rating:** 5/5

**Install:** `preinstalled (web)`

**URL:** https://www.thec2matrix.com

**Alternatives:** mitre-attack


##### MITRE ATT&CK

The authoritative knowledge base of adversary tactics and techniques — read the C2-relevant techniques (T1071 Application Layer Protocol, T1573 Encrypted Channel) and the data sources defenders link back to them.

**When:** Map which techniques your framework exercises and check the data sources you'll need to capture while testing.

**Effort:** easy  ·  **Rating:** 5/5

**Install:** `preinstalled (web)`

**URL:** https://attack.mitre.org

**Alternatives:** c2-matrix
